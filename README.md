# YouTube Music Downloader
Basic YouTube music downloader, converts the video to mp3. It can also download YouTube playlists, checking the output folder to download only the new playlist musics.

The application is in portuguese, if you speak another language, feel free to download the code and change it to your desired language.

## Installation
1. Open the terminal and run the following commands:
    
    ```
    pip install yt-dlp
    pip install unidecode
    ```

2. Run `main.py`.
